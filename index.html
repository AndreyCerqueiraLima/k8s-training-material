Diário do processador

👋 Bem-vindo ao interior de um processador!

Imagine o processador como uma cozinha que segue uma receita muito simples, uma linha de cada vez. Nosso programa é:

  1. Coloque o número 5 na bancada A
  2. Coloque o número 3 na bancada B
  3. Some A + B
  4. Guarde o resultado na gaveta 7 da despensa
  5. Fim

Para cada linha, o processador repete sempre o mesmo ciclo:

  • 🔍 Buscar: ler a instrução na memória;
  • 🧩 Entender: a Unidade de Controle descobre o que ela pede;
  • ⚙️ Executar: fazer a tarefa.

Como jogar: no Modo "Eu sou o processador", uma peça pisca; clique nela para entregar o dado que está viajando. Se errar, o guia dá uma dica. Se preferir só assistir, use o Automático. Passe o mouse sobre as peças para ver o que cada uma faz.

🎉 Programa concluído!

Em 5 instruções você viu o essencial de qualquer CPU. Seu celular faz exatamente isso, só que bilhões de vezes por segundo!
